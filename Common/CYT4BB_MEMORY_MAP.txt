CYT4BB MEMORY MAP
=================

Device family
-------------
TRAVEO T2G CYT3BB/CYT4BB, Arm Cortex-M7 single/dual core

Reference
---------
Infineon CYT3BB/4BB Datasheet, document 002-26591 Rev. *L,
2025-06-12, Figure 3 and Tables 7 through 12.

The ranges below describe the CYT3BB/4BB family address map. Reserved and
device-specific regions shall not be accessed unless the selected CYT4BB
part number and linker configuration explicitly permit the access.

Flash summary
-------------

Code Flash : 4160 KB total
             0x1000_0000--0x103E_FFFF: 4032 KB, 32-KB sectors
             0x103F_0000--0x1040_FFFF:  128 KB,  8-KB sectors

Work Flash : 256 KB total
             0x1400_0000--0x1402_FFFF: 192 KB, 2-KB sectors
             0x1403_0000--0x1403_FFFF:  64 KB, 128-byte sectors

SRAM       : 768 KB total
             SRAM0: 512 KB, first 2 KB reserved for internal use
             SRAM1: 256 KB

Project IVD layout in Code Flash
--------------------------------

0x1000_0000--0x1005_7FFF  Excluded from the current IVD calculation
0x1005_8000--0x1005_88FF  IVD signature section 1, 0x900 bytes
0x1005_8900--0x1005_8BFF  Excluded gap, 0x300 bytes
0x1005_8C00--0x101F_7FFF  IVD signature section 2, 0x19F400 bytes
0x101F_8000--0x1040_FFFF  Excluded from the current IVD calculation

Total IVD input length: 0x19FD00 bytes (1,703,168 bytes)

The current IVD end address, 0x101F_7FFF, is also the end of the first-half
large-sector region in CYT3BB/4BB dual-bank Mapping A. If bank mode, remapping,
bootloader allocation, linker sections, or the selected CYT4BB derivative is
changed, review all IVD ranges before generating or validating a signature.
